# Project instructions

- Continue until the requested deliverable is complete. Report meaningful
  progress and critical issues, not routine execution chatter.
- Optimize for useful research and delivery; do not substitute evidence
  collection for an actionable result.
- Read relevant persistent knowledge under docs before substantial work.
  Use filenames first, then document openings; do not read indiscriminately.
- Persist reusable findings promptly in English with assumptions, sources,
  methods, actual measurements, and reproducibility instructions.
- Keep project files inside the repository. Temporary files and generated
  experiment outputs live in the root .cache or .temp trees. Maintained tests
  live in tests/. Use a standard root .venv for the uv project environment.
- Use uv, a src layout, typed domain contracts, and PEP 257 English docstrings.
- Do not publish credentials, private traces, or personal local machine data.
