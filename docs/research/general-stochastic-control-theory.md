# Joint-law stochastic control of context compaction

Recorded 2026-10-06. This is a general theory layer, not another fitted
Gamma-growth model or a claim that a threshold is globally optimal. It extends
[mandatory-reload-theory.md](mandatory-reload-theory.md),
[compaction-model-selection.md](compaction-model-selection.md), and the
[working-set implementation contract](../working-set-contract.md).
The finite-policy price-envelope and exact threshold analysis are owned by
the separate exact-control track; this note concentrates on information,
state sufficiency, controlled dynamics, flow constraints and action structure.

## 1. Substantive structural conclusions

1. **Context length is not a sufficient control state in general.** We give an
   exact, nonclairvoyant four-price counterexample with equal context length,
   cache state, remaining horizon and next-demand distribution, but opposite
   optimal compact/continue actions. Both histories are reachable through the
   actual public working-set simulator. A strengthened example has positive
   charges in all four billing categories under both actions.
2. **Compaction destroys an option, not merely tokens.** A valid current-version
   file can avoid a future compulsory read. Its opportunity cost is the change
   in optimal remaining invoice, not its raw reread size. Different cache,
   task-phase and file-validity states change that opportunity cost even at
   equal length.
3. **A general joint law belongs before a named distribution.** Correlated,
   nonstationary growth, mutation, recovery output and timing can be represented
   by conditional history kernels. No iid assumption, finite-dimensional
   Markov state, exponential duration or renewal structure is automatic.
4. **Bellman recursion and occupation flows are dual descriptions of the same
   finite controlled invoice.** For finite observable sufficient state they
   yield exact evaluation/control and checkable lower bounds. A history-state
   formulation is formally general but not automatically a scalable algorithm.

The counterexample is a proof of insufficiency, not a simulation curve.
The simulation is used only to check that its transparent exact ledger agrees
with the implemented semantics in every branch.

## 2. Primitive problem and information model

Fix N ordinary task actions. Include every intervening compactor and compulsory
recovery request in the invoice, but none increases the ordinary-action count.
For policy pi, let the four disjoint aggregate billed quantities be

\[
U_N^\pi=(I_N^\pi,W_N^\pi,R_N^\pi,O_N^\pi),\qquad
J_N(\pi)=E_\pi[p\mathbin{\cdot}U_N^\pi].
\]

All prices are finite nonnegative USD/token. A provider normalization makes
input, cache-write and cache-read categories disjoint. Generated summaries and
recovery commands count as output; tool-returned file payloads do not.
Non-token overhead can be added explicitly. Assume each macrostep completes
its ordinary action and has finite expected invoice; infeasibility/loop failure
is an explicit absorbing outcome, not a cheap truncated successful invoice.

### 2.1 Filtration, chronology and no oracle

Let tau_n be the decision boundary before ordinary action n, and F_n the
sigma-field generated by everything revealed to the controller by that boundary:
past task instructions, observed files/versions, tool results, cache telemetry,
elapsed times, invoices, earlier control decisions and declared current-task
metadata. Exogenous gaps or version changes already observed before deciding
are in F_n; unrevealed future requirements and future outputs are not.

The controller chooses an F_n-measurable action A_n, or uses a randomized kernel
pi_n(da|F_n) with independent private randomization. Here A_n may choose
continue, compact with a preservation/restoration specification, or another
explicit context-management intervention. The next ordinary task operation is
not replaced with an invented easier one. Requirements and output can remain
unknown when the intervention is selected.

After the intervention, compactor/recovery observations are revealed in their
actual order, required facts are restored, and one ordinary action completes.
Internal recovery decisions must be adapted to those microevent observations.
A trace replay that reads all future demand arrays before choosing A_n is a
clairvoyant offline benchmark, not an online control policy. Our exact example
averages the unrevealed Bernoulli mark *after* selecting the action.

### 2.2 General conditional joint law

Let H_n be the observable decision history. For admissible action a, specify
the joint kernel

\[
\mathcal K_n(d u,d t,d H'\mid H_n,a),
\]

of the complete next macrostep's billed usage u, elapsed duration t and next
observable history H'. This includes compaction, preservation, compulsory
loads, version updates, cache expiry, ordinary retained input, generated output,
and the revealed observations. The usage and next state are generally
dependent; large recovery payloads can simultaneously increase duration,
miss probability, output, and subsequent retained length.

One can instead start from a probability space carrying an arbitrary joint
primitive random field and nonanticipative event maps. That field need not
factor into independent growth/gap/demand/reset marginals. A common primitive
coupling across policies is useful for comparison when it faithfully realizes
their conditional laws; forcing identical *realized outputs* across policies
is a stronger controlled-replay restriction, not an identity of the general
model.

In particular, ordinary model output may depend on the retained context and
management action through K. The implemented fixed-output replay is a useful
submodel holding ordinary input/output marks invariant to isolate billing.
Both versions keep the ordinary-task count fixed. If task requirements or
success semantics are also made policy-dependent, declare that extension and
its objective explicitly; do not silently mix it into a fixed-task experiment.

Under standard Borel observation/action spaces, regular conditional kernels
provide this formulation. Measurability, integrability, action feasibility and
existence of optimal selectors must be supplied for general-space theorems.
Our exact results below require only finite sets and finite rational invoices.

## 3. Hybrid state and the sufficient-statistic question

An engineering candidate state is

\[
S_n=(n,X_n,\mathcal P_n,\mathrm{ages}_n,R_n,v_n,g_n,z_n,b_n),
\]

where X is physical retained length; P/ages describe matching cache boundaries;
R contains valid model-visible file/version/range facts; v current versions;
g read-guard certificates; z observed task phase; and b a posterior for an
explicitly modeled hidden environment when needed. Physical old-version text
can remain billed after its fact becomes invalid. External file availability,
semantic observation availability, read permission and cache warmth differ.

This tuple is only a candidate. The exact sufficiency condition is:

> For every pair of observable histories mapped to the same S_n, and every
> admissible action a, the conditional joint law of next billed usage and next
> sufficient state is the same; admissible actions also depend only on S_n.

Equivalently, there exists a policy-independent controlled kernel
`K_n(du,dt,ds'|s,a)` satisfying the conditional law under all admissible
histories/policies, not merely matching unconditional marginals in one run.
This is what permits a controlled Markov representation. If a latent phase
changes future use hazards, a cache age omits an entry's true lifetime law, or
summary quality depends on an omitted earlier obligation, the tuple can fail.

The always-valid fallback is S_n=H_n: histories append and therefore encode
the available information. It is a formal representation, not a license to
claim a low-dimensional Markov model or a tractable algorithm. A belief state
is sufficient only after specifying a suitable latent-state/observation model;
calling an arbitrary vector an embedding does not prove sufficiency.

### Continuous time between request jumps

Cache ages evolve continuously; tool completion, requests, edits and compact
resets are discrete events. This is naturally a stochastic hybrid controlled
process. Under a sufficient Markov state, deterministic interevent flows and
state-dependent jump hazards, it may be a piecewise-deterministic Markov
process (PDMP), as in [Davis 1984](https://doi.org/10.1111/j.2517-6161.1984.tb01308.x).
Arbitrary heavy-tailed or history-dependent durations need residual-age state
or a general semi-Markov/history model; they are not automatically PDMPs with
exponential request clocks.

Compaction is impulse-like: a paid intervention causes a discontinuous reset.
It does not stop the ordinary task. Continuous-time impulse-control theory
motivates intervention and continuation regions, but its discounting,
nonexplosion and Markov assumptions do not transfer without checking. At
request boundaries the embedded finite model is often the simplest faithful
tool, rather than importing a full continuous-time generator.

## 4. Finite evaluation and optimal control

Use n=0,...,N for completed ordinary actions. For a sufficient observable state,
define

\[
c_n(s,a)=\int p\mathbin{\cdot}u\ K_n(du,dt,ds'\mid s,a),\qquad
P_n(ds'|s,a)=\int K_n(du,dt,ds'|s,a).
\]

Correlation between usage and next state is permitted: linearity of conditional
expectation, not independence, allows the separate cost plus next-value form.
For a prescribed policy pi,

\[
V_N^\pi=0,\qquad
V_n^\pi(s)=\int\left[c_n(s,a)+\int V_{n+1}^\pi(s')P_n(ds'|s,a)\right]
                 \pi_n(da|s).
\]

The optimal finite ordinary-task invoice satisfies

\[
\boxed{V_N=0,\qquad
V_n(s)=\min_{a\in\mathcal A_n(s)}
  \{c_n(s,a)+P_n^a V_{n+1}(s)\}.}
\]

For finite states/actions, backward induction proves this statement: condition
on the first control and next state, then minimize the remaining problem;
choose a minimizing action at each stage. A deterministic nonanticipative
minimizer exists. Randomization cannot improve an unconstrained finite-state
expected-invoice objective, since a weighted average cannot fall below the
smallest available action value. Additional explicitly imposed expectation
constraints can make randomization useful; none are implicit here.

The identical recursion on observable histories is general but grows with the
history tree. For general Borel spaces use infimum and appropriate measurable
epsilon-selectors unless existence of a minimizing selector is established.

### Atomic versus strict-trigger semantics

For atomic continue/compact control, each action includes at most one compact
and then one ordinary action; K_continue and K_compact are independent of a
scalar threshold h. A threshold selects an action, rather than altering the
kernel definition. Extra recovery invoices are included before n increments.

If internal preservation/recovery decisions are themselves controllable after
new observations, a macroaction must specify the complete adapted within-step
contingent plan. Otherwise expand those microdecision states and apply Bellman
there. A kernel for the bare label "compact" cannot be policy-independent while
silently allowing unspecified later control choices inside it.

A strict recheck that repeatedly compacts when restoration exceeds h introduces
additional decisions/events. It cannot be hidden inside an h-independent
atomic compact kernel. Expand microstates for restore/recheck/retry count, or
retain an explicitly h-dependent strict macro kernel. If retry count is bounded,
pad unused event slots with zero-usage identity transitions for finite-flow
analysis. If unbounded, nonexplosion/termination conditions are needed. An
infinite compact/reread loop is not a limiting zero-cost policy.

For the present finite invoice, V_N=0 means no pointless terminal compaction.
N includes ordinary actions only; inserting recovery calls does not shrink N.
The original optimization over scalar thresholds is a restricted policy family;
optimizing all state-dependent controls answers a larger comparison question.

## 5. Stop/continue advantage and state opportunity costs

For binary atomic actions, write the full-future action values

\[
Q_n^c(s)=c_n(s,c)+P_n^cV_{n+1}(s),\qquad
Q_n^k(s)=c_n(s,k)+P_n^kV_{n+1}(s).
\]

Define the signed intervention disadvantage

\[
\boxed{\Delta_n(s)=Q_n^k(s)-Q_n^c(s).}
\]

Compact is optimal if Delta<0, continue if Delta>0, and ties are genuine.
The decomposition

\[
\Delta_n(s)=
 [c_n(s,k)-c_n(s,c)]+
 [(P_n^k-P_n^c)V_{n+1}](s)
\]

separates immediate invoice from the value of the reset's changed future state.
The second term includes lost current facts, lost warm boundaries, different
future read guards, altered compulsory loads, summary sufficiency and changed
stopping opportunities. Comparing only compressor output or immediate length
reduction omits that state opportunity cost. At the last ordinary action the
future term is zero, so our example is already decisive without guessing a
long-run law.

For a fact e define an analytical state contrast
`Lambda_n(e;s)=V_n(s_without_valid_e)-V_n(s_with_valid_e)` while holding physical
token length, cache state and conditional future environment fixed. It is a
discrete state shadow value, not a universal per-file price. If the only change
is additional usable information/permission, the valid state can emulate the
missing state's actions at no extra charge, and the conditional future law is
the same, then Lambda>=0 by policy emulation. If keeping the file adds tokens,
breaks prefix matching or changes the demand posterior, these hypotheses fail;
preservation can cost more even while avoiding rereads.

The value is generally nonadditive across facts: one recovery request can batch
several files, and preserving a bundle can change both the cache boundary and
future compact decisions. Assigning each file an independent scalar penalty
is an approximation requiring a separability argument.

## 6. Exact same-length opposite-action counterexample

### 6.1 A last-action ledger with symbolic prices

Let current context be x, live prefix w, stable reset base b_0, generated
summary c, compactor instruction k, ordinary uncached suffix e, newly retained
ordinary input b and ordinary output o. There is one file of size d, valid
resident indicator r in {0,1}, and an unrevealed requirement mark Z with
P(Z=1)=a. No version change occurs in this single step. Compaction discards
the file observation, preserves no warm prefix, and generates c. Missing
required payload is appended before the ordinary request without a separate
model round. All ordinary inputs are cache eligible.

The expected disjoint usage vectors are

\[
\bar U^c=(e,\ x-w+b+a d(1-r),\ w,\ o),
\]

\[
\bar U^k=(x-w+k+e,\ b_0+c+b+a d,\ w,\ c+o).
\]

The compactor reads the old warm prefix once and processes the cold tail as
uncached input; it does not write obsolete history. The reset prefix is cold,
and a file tool result is later input, not model output. No terminal bill exists.
Subtracting gives the exact last-step control disadvantage

\[
\boxed{\Delta(r)=p_i k+(p_i-p_w)(x-w)
                  +p_w(b_0+c)+p_o c+p_w a d r.}
\]

The cache-read rate appears in both full invoices and cancels from this
particular one-step difference, because continuing reads w once whereas
compacting reads that same old w once. It is not ignored or set to zero.
The lost valid-file option contributes `p_w*a*d*r`. When r=0 both actions
already require that possible payload, so that common restoration cancels.

Thus whenever the base term D_0 satisfies

\[
-p_w a d<D_0<0,
\]

the missing-file state strictly compacts while the valid-file state strictly
continues, despite identical x,w and demand distribution. This is an open
parameter region, not an isolated floating-point equality.

### 6.2 Rational example with all four categories positive

Use the project's illustrative prices
`p=(3,15/4,3/10,15)/10^6` USD/token and parameters

| Parameter | Value |
| --- | ---: |
| Current x / live prefix w | 10,000 / 1,000 |
| Reset stable base b_0 / generated summary c | 1,000 / 100 |
| File d / unrevealed requirement probability a | 1,000 / 1/2 |
| Compactor instruction k / ordinary suffix e | 128 / 128 |
| Ordinary retained input b / generated output o | 2 / 2 |
| Additional recovery model rounds / wrappers | 0 / 0 |

Every following row has positive input, write, read and output quantities:

| Observable fact state | Action | E[I] | E[W] | E[R] | E[O] | Exact expected USD |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| File valid | Continue | 128 | 9,002 | 1,000 | 2 | 0.0344715 |
| File valid | Compact | 9,256 | 1,602 | 1,000 | 102 | 0.0356055 |
| File absent | Continue | 128 | 9,502 | 1,000 | 2 | 0.0363465 |
| File absent | Compact | 9,256 | 1,602 | 1,000 | 102 | 0.0356055 |

The base disadvantage is D_0=-0.000741, and `p_w*a*d=0.001875`.
Therefore Delta(valid)=+0.001134 and Delta(absent)=-0.000741.
**The same x,w,N and future law require opposite controls.** At decision time
the controller knows r, but does not know Z; costs average its two branches.

These states are actually reachable using `simulate_working_set`:

- Stable base 1,000 is warm initially. First ordinary action has zero retained
  input and produces 8,000 output tokens followed by an automatic 1,000-token
  file observation in the valid-state history. Result: X=10,000, prefix=1,000,
  current file and qualifying guard present.
- The other history produces 9,000 output tokens and no file observation.
  Result: the same X and prefix, but no valid file fact/guard.
- Before the second ordinary action there is no expiry or mutation. Its file
  requirement is an independent Bernoulli(1/2) mark, not revealed before the
  compact/continue choice. Its ordinary input/output are fixed at 2/2.
- Threshold 10,000 causes one compaction only before the second action;
  infinity continues. The first action's invoice is sunk and subtracted
  separately for each history. Different past output charges do not affect
  the conditional remaining-action problem.

There is no opaque state injection, private-engine call, simulation search,
future-demand oracle or alteration of the ordinary action to make compaction
look productive. Each control is checked on both possible Z values.

### 6.3 A cold-prefix variant with identical sunk invoices

The maintained experiment also uses b_0=w=0 and d=4,000 with all other values
unchanged. First action in the valid history appends 6k background input plus
a compulsory 4k file; the other appends 10k background input without the file.
Both write 10k, generate zero output, and have identical sunk first invoices.
A gap greater than TTL makes both prefixes cold before the second decision.

| Fact state | Continue USD | Compact USD | Optimum |
| --- | ---: | ---: | --- |
| Valid current file | 0.0379215 | 0.0401805 | Continue |
| Missing current file | 0.0454215 | 0.0401805 | Compact |

Here the valid-file state shadow value under optimal control is
`0.0401805-0.0379215=0.002259`, not the raw expected write saving 0.0075:
the missing-file controller can mitigate its disadvantage by compacting.

### 6.4 Formal insufficiency and a strict regret lower bound

**Proposition.** Suppose two positive-probability observable states have the
same aggregate y (here y=(x,w,N)), but unique optimal actions differ. Then no
policy measurable only with respect to y can be optimal in both states.

**Proof.** A deterministic y-policy selects the same action at both states,
violating one strict optimum. A randomized y-policy selects compact with the
same probability rho in both. Write Delta_A>0 for the valid state and Delta_B<0
for the absent state. With state probabilities q and 1-q, its regret over
state-aware control is

\[
q\rho\Delta_A+(1-q)(1-\rho)(-\Delta_B).
\]

This affine expression in rho has minimum
`min{q*Delta_A,(1-q)*(-Delta_B)}>0` for 0<q<1. QED.

For the equally weighted cold-prefix example, optimal state-aware remaining
invoice is USD 0.039051; the best length-only randomized/deterministic invoice
is USD 0.0401805. Unavoidable regret is exactly `2259/2000000` USD = 0.0011295.
For the all-four-active variant it is USD 0.0003705. This disproves a universal
scalar-length optimum even when allowing randomized thresholds. It does not
say a scalar threshold cannot be useful on a restricted homogeneous workload.

### 6.5 A complete Bellman/LP certificate, not just an observed cost gap

Restrict the decision problem explicitly: **one remaining ordinary action**,
observable initial state A or B with equal probability, and admissible actions
continue/compact with the first-use reset semantics already specified. This is
a reachable-state one-stage structural benchmark, not the globally unrestricted
two-action control problem that generated the histories. The first invoices
are sunk; no other preservation action or summary policy is available here.

In occupation-column order `(A-continue,A-compact,B-continue,B-compact)`, the
flow constraints and exact invoice coefficients are

\[
F\mu=b,\quad\mu\ge0,\qquad
F=\begin{pmatrix}1&1&0&0\\0&0&1&1\end{pmatrix},\quad
b=\begin{pmatrix}1/2\\1/2\end{pmatrix},
\]

\[
c=\frac{1}{2{,}000{,}000}
       (75843,80361,90843,80361)^\top.
\]

Choose dual state potentials

\[
v=(75843,80361)^\top/2{,}000{,}000.
\]

All four Bellman lower-bound inequalities `F^T v <= c` hold with exact slacks

\[
c-F^\top v=(0,2259,5241,0)^\top/1{,}000{,}000.
\]

The feasible occupation vector `mu_*=(1/2,0,0,1/2)` achieves

\[
c^\top\mu_*=b^\top v=39051/1{,}000{,}000=0.039051.
\]

Thus the policy upper bound and dual lower bound coincide, proving this
restricted state-aware optimum exactly. A scalar rule at X=10,000 has to
choose the same action in A/B. Continuing both costs USD 0.0416715;
compacting both costs USD 0.0401805. A randomized scalar rule is a mixture of
these costs and cannot improve the better endpoint. Its optimum is therefore
`80361/2000000`; the exact restriction gap is `2259/2000000` = USD 0.0011295,
or **2.8110650689% of the best scalar-threshold invoice**.

The structural result persists on the open price region defined by the actual
ledger coefficients

\[
10128p_i-7900p_w+100p_o>0,
\qquad 10128p_i-9900p_w+100p_o<0.
\]

For the all-four-active variant the corresponding region is
`9128*p_i-7400*p_w+100*p_o>0` and
`9128*p_i-7900*p_w+100*p_o<0`. The p_r coefficient cancels in these particular
advantages, although every all-four-active action invoice includes positive
read tokens at a strictly positive price. These inequalities are computed
from the real branch ledgers, not inferred from an optimized simulation curve.
The experiment exports F, b, c, v, the four exact slacks, primal occupation,
equal primal/dual objectives and threshold restriction gap in its JSON artifact.

## 7. Occupation-measure flow constraints

For finite observable sufficient state/action sets, let
`mu_n(s,a)=P_pi(S_n=s,A_n=a)` and `eta_n(s)=sum_a mu_n(s,a)`.
The necessary forward flow constraints are

\[
\sum_a\mu_0(s,a)=\nu_0(s),\qquad \mu_n(s,a)\ge0,
\]

\[
\boxed{\sum_a\mu_{n+1}(s',a)
 =\sum_{s,a}\mu_n(s,a)P_n(s'|s,a)},\qquad n=0,...,N-2,
\]

with mu zero on inadmissible actions. The terminal state law eta_N is obtained
by the last transition and has no decision invoice. Then

\[
J_N(\pi)=\sum_{n=0}^{N-1}\sum_{s,a}\mu_n(s,a)c_n(s,a).
\]

**Sufficiency of the flows.** Given nonnegative mu satisfying these constraints,
define `pi_n(a|s)=mu_n(s,a)/eta_n(s)` when eta_n(s)>0, and any feasible action
off support. Induction from nu_0 shows this nonanticipative Markov policy
reproduces mu at every stage. Thus finite controlled evaluation/optimization
can equivalently use the occupation-flow linear program.

This converse requires observable sufficient state and a genuine controlled
kernel. If one writes flows over an unobserved latent state and permits
pi(a|latent), the LP may construct an omniscient controller. Add belief/history
state or explicit information constraints. If aggregate X is not sufficient,
conditional transition probabilities `P(nextX|X,a)` averaged from one policy
can change under another policy, so those averaged flows do not define a
policy-independent control model.

The history-state version gives equally valid finite-horizon flow equations
on the history tree, without iid or physical-state Markov assumptions.
For general Borel spaces replace sums by measures, use disintegration and
appropriate measurable feasibility conditions; we do not claim arbitrary
infinite-dimensional LPs are automatically solvable or have no relaxation gap.

Primary finite-flow exposition:
[Akian, dynamic programming notes, Chapter 7, Propositions 7.7-7.8 and Theorems 7.11-7.12](https://www.cmap.polytechnique.fr/~akian/cours-ensta/Lecture_Notes_Akian-ENSTA-Saclay.pdf).
Peer-reviewed impulse-measure extension:
[Piunovskiy and Zhang, JMAA 2021](https://doi.org/10.1016/j.jmaa.2021.125070).
The latter establishes equivalences under its own hypotheses; our finite proof
above is self-contained and does not import its continuous-system assumptions.

### Value potentials and checkable lower bounds

Let v_N=0 and choose potentials satisfying

\[
v_n(s)\le c_n(s,a)+\sum_{s'}P_n(s'|s,a)v_{n+1}(s')
\quad\hbox{for every feasible }(s,a).
\]

Multiplying by mu and summing makes intermediate state terms cancel by the
flow constraints. Hence `E_nu0[v_0]<=J_N(pi)` for every admissible policy.
At the Bellman solution v=V, a minimizing action attains equality and the
bound is sharp. This gives a theory-facing verification certificate, not only
a numerical curve: a feasible policy supplies an upper bound; a valid value
potential supplies a lower bound. Their gap measures remaining control work.
The potentials are state opportunity costs; physical file lengths alone do
not identify them.

## 8. When renewal reduction is legitimate

A compaction is an intervention time, not automatically a renewal epoch.
If complete post-reset states, primitive future laws and billed cycle marks
restart iid, with integrable cycle usage Q and 0<E[T]<infinity ordinary actions,
the long-run rate is `E[Q]/E[T]`. It is not E[Q/T], and finite N still needs
first/final-cycle corrections. Persisted project phase, current versions,
read guards and cache ages can prevent iid regeneration even if summary length
is constant.

With a sufficient stationary Markov reset-state chain and invariant law pi,
an ergodic ratio can instead average conditional cycle reward and ordinary
length against pi. Its existence, convergence and integrability require
assumptions; a general nonstationary joint law may have no useful renewal
reduction at all. Finite Bellman/flow analysis remains well-defined.

The independent first-use formula `P(K<=T)=1-E[(1-a)^T]` applies only when
file-demand marks are independent of the cycle clock. Once compulsory file
loads count toward retained X, first use can shorten T. The exact example
in mandatory-reload-theory.md Section 5 has T=1 after a first-step load and
T=2 otherwise; a=1/2 gives actual probability 0.75 versus independent-clock
plug-in 0.625. No replacement of correlated variables by their means repairs
that joint-law error.

The predictable occupancy identity in that note is a useful qualified result:
constant conditional hazard a and a predictable ordinary-cycle boundary imply
`E[(T-K)_+]=E[T]-P(K<=T)/a`, without independence of T and K. If the hazard is
history-dependent, the compensator is the sum of its conditional hazards over
missing-file opportunities; replacing it by a constant is another assumption.

## 9. Grounding and limits of external theory

| Primary external source | What transfers | What does not transfer automatically |
| --- | --- | --- |
| Davis, JRSS B 1984 | Hybrid continuous ages plus stochastic jumps, sufficient-state PDMP construction | Markov sufficiency, jump hazards and nonexplosion for arbitrary agent history |
| Dufour/Piunovskiy, Advances in Applied Probability 2015 | Distinction between intervention/continuation regions and intervention costs | Infinite-horizon discounted conditions or a scalar monotone threshold theorem |
| Piunovskiy/Zhang, JMAA 2021 | Occupation measures and rigorously conditioned impulse-control LP equivalence | No-relaxation-gap claims for a different information structure |
| Anthropic context-editing docs | Clearing tool results invalidates affected prefixes and new writes rebuild eligibility | Universal cold-all-prefix assumptions or necessity to reread every forgotten file |
| Anthropic context-engineering practice | Up-front guidance and just-in-time file retrieval are distinct mechanisms | Independent first-use marks, known summary sufficiency, or a fitted reset law |

Production documentation explicitly treats cache invalidation and subsequent
reuse as consequences of editing strategy:
[Anthropic context editing, caching section](https://platform.claude.com/docs/en/build-with-claude/context-editing).
This supports carrying prefix identity in the state, not equating semantic
availability with caching. The public API/implementation contract decides which
file facts and guards survive. The exact invoice model is an engineering
mechanism model; summary quality or semantic sufficiency is an explicit
assumption, not something proved from token counts.

The academic tools here are mature enough for exact small-state research.
They are not a demand to install reinforcement-learning infrastructure or a
generic event engine. A practical next contribution is an observable-state
Bellman controller for a small declared joint law, plus a state aggregation
error certificate or held-out decision-regret test. Claims of a universal
threshold should wait for actual monotonicity/single-crossing hypotheses.
